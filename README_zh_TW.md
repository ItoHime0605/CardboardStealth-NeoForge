# Cardboard Stealth／紙箱潛行 — 0.1.6-alpha 開發原始碼

> **0.1.2-alpha 已成功透過 NeoForge/Gradle 編譯；0.1.5-alpha 仍待編譯與 Minecraft 專用伺服器實測。** 本工程是原始碼，不是可直接安裝的模組 JAR。

環境：Minecraft 1.21.1、NeoForge 21.1.x、Java 21、Curios 9.5.1、Zombie Awareness 1.13.2。此工程不需要 Zombie Extreme。

## 0.1.3 既有功能（前版）（2026-11-06）

- 修正 Gradle `localRuntime` 不存在的問題，改用 `runtimeOnly`；0.1.2-alpha 已由 GitHub Actions 成功產生 JAR。
- 紙箱低跳會同時在玩家客戶端與伺服器限制跳躍速度，減少跳躍預測不同造成的回彈；初速改為 0.240，**實際半格高度仍需遊戲測量**。
- 不再透過聲音發生位置附近是否有紙箱玩家來取消 Zombie Awareness 腳步追蹤，避免誤刪其他玩家的聲音。ZA 音量縮減、感知抑制仍需多人連線實測。
- 玩家重新出生、切換維度時清理紙箱狀態；造成實際傷害（包含部分彈丸來源）或使用道具時，會中斷偽裝。
- 保留原本追擊：已鎖定玩家的殭屍不會因紙箱突然清除目標。靜止 1.25 格、移動 3.5 格是防止**新索敵**的半徑，不是瞬間清仇恨。
- 正式紙箱 3D 外觀、上半磚後傾動畫仍**等待使用者提供參考圖**，這輪沒有製作。

## 0.1.1 基礎機制

1. **靜止／移動兩段識破半徑（新版需求）**
   - 紙箱內完全靜止：殭屍在 **1.25 格（含）** 內能識破；距離 **超過 1.25 格** 時不會因直接辨識選擇新目標。
   - 紙箱內移動：殭屍在 **3.5 格（含）** 內能識破；距離 **超過 3.5 格** 時不會因直接辨識選擇新目標。
   - 判斷使用三維距離平方；距離相等時視為可識破，避免邊界不明確。
   - 伺服器每個玩家 tick 記錄本人的位移，不需要每 tick 掃描附近全部殭屍。忽略小於 0.01 格的座標誤差；停止移動後再經過約 2 tick 才判定靜止，跳躍期間視為移動。
   - 已鎖定玩家的殭屍**不會**因為距離超過識破半徑而被清除目標。
2. **保留原本殭屍仇恨／搜尋**
   - 不再強制對附近殭屍 `setTarget(null)` 或 `navigation.stop()`。
   - 玩家啟用紙箱前，確認是否有符合條件的殭屍仍將自己作為目標；沒有真正脫離追擊就不能利用紙箱重入潛行。
   - Zombie Awareness 自訂 `ZAUtil.isEnemy` 和 NeoForge 新目標事件使用相同識破規則。
   - 失去目標後的原有循聲、循氣味搜尋路徑不會被整批刪除。
3. **移動物理**
   - 進入紙箱時賦予 `-40%` 移動速度屬性修正，離開即移除。
   - 蹲行可沿用原版跨越半格障礙；跳躍初速限制為 `0.245`，設計目標為約半格高的低跳。
   - 跳躍產生小量 Zombie Awareness 聲音線索，原本的腳步、落地音量按比例降低。
4. **既有原型保留**
   - Curios 紙箱槽、蹲住 20 tick 啟動、放開蹲下結束；網路同步；上身紙箱渲染原型；中文名稱與配方。
   - 現有三種箱子的像素材質只是**舊的暫用原型**，正式 3D 外觀及上半磚向後傾斜動畫**尚未製作**，等使用者提供圖片再做。
   - `BoxDetectionRules` 為可獨立測試的純 Java 判定器。

## 重要限制與後續工作

- **目前只有自動編譯／純 Java 規則測試**：不代表遊戲內運作或多人連線已通過驗收。
- Zombie Awareness 音效追蹤以座標為參數；0.1.5-alpha 新增伺服器實體聲音來源記錄，只攔截紙箱玩家自己的腳步／落地聲，無來源的座標聲響仍保持原樣。
- 半格跨越和半格跳躍高度，目前是依據原版移動模型的程式設計值，需要遊戲實測再校準，不保證其他移動／重力模組下也恰好半格。
- 目前 Zombie Awareness 跟 `fooled_by_box` 標籤支援的怪物能介入索敵；未來更換殭屍模組時需要額外對接它的 AI。
- 仍需完成槍械開火中斷、玩家死亡／登出、原版與特殊怪物追蹤、多人同步、Curios 槽位，以及裝甲／手持物件的相容實測。

## 程式距離規則的本機測試（不依賴遊戲）

在專案根目錄執行（原始判定規則）：

```sh
mkdir -p /tmp/cardboard-rules
javac -encoding UTF-8 -d /tmp/cardboard-rules \
  src/main/java/tw/zonezero/cardboardstealth/BoxDetectionRules.java \
  tests/BoxDetectionRulesTest.java
java -cp /tmp/cardboard-rules BoxDetectionRulesTest
```

預期結果：`PASS: 14/14 detection and existing-lock checks`。

## NeoForge 專案建置

此 ZIP 不包含 Zombie Awareness／Curios 的 JAR，也不含 Gradle Wrapper。準備 JDK 21 與 Gradle 8.10.2 後，在有網路並可連接 NeoForge 與依賴倉庫的環境執行：

```sh
gradle --no-daemon build
```

理論輸出檔名：`cardboardstealth-neoforge-1.21.1-0.1.6-alpha.jar`，**只有真正編譯成功後**才可用於測試伺服器。GitHub Actions 工作流程也會使用這個版本名稱。


## 測試提醒

目前 GitHub Actions 成功只代表建置完成，**尚未測試安裝於專用伺服器**。在正式給玩家安裝之前，仍須確認 Curios 裝備槽、客戶端紙箱渲染、Zombie Awareness 偵測、切維度、死亡重生，以及 TaCZ 開槍取消偽裝的實際效果。不要把編譯成功當作遊戲內功能都已通過。

## 0.1.5-alpha 新增項目

1. Zombie Awareness 聽覺改成**根據實際發聲玩家判定**，避免貼著紙箱的另一位玩家腳步聲也被抑制。
2. 紙箱的腳步與落地聲不是完全消失：保留原本追蹤強度約 1/16 與 1/8 的微弱聲響線索。
3. 避免跳躍額外播放方塊腳步音效引發第二次完整的殭屍感知；仍保留跳躍時的微弱追蹤事件。
4. 維持先前已完成的客戶端低跳、生命週期清理、右鍵使用道具與攻擊／受到傷害解除偽裝。
5. **未開始正式紙箱外觀製作**：外觀、貼圖與半磚後傾動畫等使用者參考圖片後再處理。

注意：伺服器實體聲響追蹤要做實際 Minecraft／Zombie Awareness 測試；Gradle 編譯只驗證程式碼可建置。

## 0.1.5-alpha 半格跨越與客戶端音量修正

- 紙箱啟動時除了移速 -40%，另對玩家增加暫時的 `STEP_HEIGHT -0.1` 屬性修正；以原版玩家的 0.6 格跨步高度為基準，紙箱狀態降為 0.5 格，仍能跨越半磚。離開紙箱自動移除修正；其他模組若自行修改跨步高度，需遊戲實測相容。
- 先前僅伺服器會以玩家 NBT 判斷紙箱音效；0.1.5-alpha 另使用 `ClientBoxState` 判斷客戶端實際發出的玩家腳步／落地聲量，讓自己和旁人的聽感與伺服器偵測邏輯一致。
- 只對客戶端的聲音事件處理，避免整合伺服器時重複降低音量。
- 正式模型／紙箱走上半磚後傾動畫仍未製作，待使用者參考圖片。

## 0.1.6-alpha（聲音設定尊重與互動防偽裝）

- Zombie Awareness 聽覺追蹤關閉、或僅限主世界且玩家不在主世界時，**跳躍與腳步不能自行補生新的聲音追蹤節點**；符合原模組 `ZAUtil.canSpawnTraceQuickCheck` 的規則。
- 玩家在紙箱內右鍵互動方塊、實體（含開啟容器和與 NPC 互動）會中斷偽裝，與攻擊、使用物品限制一致。
- 把「已經鎖定玩家」加入純 Java 判定函式與迴歸測試。遠離殭屍但未真正脫離鎖定，不能靠紙箱清仇恨。
- 純 Java 測試擴充至 14 項，並透過 GitHub Actions 驗證。
- 正式紙箱外觀仍未製作，待使用者提供參考圖後再製作模型及半磚上坡後傾動畫。

**驗收限制**：以上是程式邏輯與自動建置驗證，仍需要 Minecraft 客戶端＋專用伺服器遊戲內實測。
